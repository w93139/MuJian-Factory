# 前端瘦身与双入口交付（2026-10-10）

本轮在 8729f8b 集成版本基础上，仅整理前端及相关检查、运行文档。保留光影叙事设计、原业务核心和旧操作界面；未修改 backend 或真实项目数据。技术检查通过后仍须用户验收，旧入口不会自动停用。

## 整理结果

- 正式 frontend 删除 concepts 模拟业务、模拟权限/本地状态、另外两套 guided/gallery 设计、演示测试与根 apps 三套启动壳；删除仅服务演示的媒体生成脚本。
- 将光影界面实际使用的波形动效、聚光卡片、基础控件及样式提取到 frontend/ui，阶段常量留在 frontend/live/stages.ts。保留来源许可证，根 THIRD_PARTY_NOTICES.md 原样不动。
- 移除未使用的 gsap、motion、tailwind-merge 三项直接依赖，以及已无调用的旧 API 函数和文本分镜解析器。原业务六阶段、沙盒、三条快捷流水线与媒体功能仍保留。
- 合并重复 artifact PATCH 封装，统一由 frontend/lib 处理 HTTP 错误。旧参考图/视频提示词保存失败时显示原因、保留草稿，成功重试才退出编辑。
- 素材选版只 PATCH 当前片段，保存期间串行处理，成功才更新选择；失败保持原选择，避免其他片段的旧值覆盖新值。继续沿用后端既有按 ID 合并行为。
- 去掉没有实现的 movie/micro/logline 假按钮，保留明确的能力说明。修复手机端首页波形负边距导致的横向溢出。
- 增加构建边界检查，防止正式源码重新依赖 concepts、构建产物重新带入演示状态或未选方案；Docker 上下文排除多入口缓存与测试材料。
