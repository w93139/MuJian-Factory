# 冻结旧版对照与原数据接入验收

## 基线与范围

本次以 `旧版完整备份/frontend/` 为真正基线。固定 Git 提交 `2ab1fe77cf835d58fd13d799308cb49c3a2b6ffd` 的 63 个已跟踪前端文件与备份逐字一致；使用 `scripts/run-frozen-frontend.py` 导出副本运行，不在备份中构建。不再把当前源码的 `NEXT_PUBLIC_MUJIAN_LEGACY=1` 当作冻结基线。

本轮生产修改只涉及前端展示：恢复访客案例首屏位置，清除 `?view=projects` 隐藏创作区的遗留分支，去掉沙盒无操作意义的“创意强度暂不可配置”文字。没有修改后端源码、接口、生成规则、权限、数据格式或数据路径。光影创作首页、左侧导航与任务、侧栏收起记忆保留。

## 实际连接

3110 光影前端与 3112 冻结旧版均连接 8000 正式后端，读取根目录 `backend/code/`。原有两个六阶段项目、五条流水线任务和沙盒历史已接入。五条任务中四条完成、一条本来失败；保留真实状态。旧合成测试后端18785不再是这两个入口的数据源。

逐文件验收结果：56 个本地媒体（25视频、26图片、5音频）经3110代理均返回200且 Content-Length 与磁盘一致；JSON 中47个唯一的本地媒体引用全部指向存在的文件。两个原项目成片与四个已完成流水线成片均通过浏览器 readyState 与播放时间前进验证。没有为测试触发新的模型生成。

## 明确保留的差异

这不是逐像素复制旧版，以下差异有既定依据，不改变原创作顺序：

- 用户选定的光影主视觉改变首页大标题和统一内容起始高度；没有拆分或搬动表单入口。
- 用户要求去掉技术性解释小字，剧本内容向上24px、分镜标题宽度随之收紧；原操作位置和分组关系保留。
- 之前已修复的保存失败保留草稿、冲突检查、URL前进后退、模型能力参数、剧集正文编辑仍保留。沙盒补充能力参数；图片拼接模式隐藏不生效的视频分辨率，不能为了像素一致恢复无效参数。
- 冻结旧版手机CSS会在收起后仍强制248px侧栏，遮挡点击；新版保留已有修复，不复制该缺陷。测试明确记录这个差异，不把旧版也描述为正常。
