# 原版布局恢复与光影换肤边界

本轮目标：导航、进行中任务、已完成/待确认任务、账户和设置统一恢复到左侧，复用原版 AppShell、收起展开和本地记忆。保留光影背景、标题与深色视觉。

边界：不改后端、接口和生成逻辑，不修改旧版完整备份与新前端设计版。首页表单、六阶段、沙盒、三条流水线、设置的原组件、控件顺序和默认显隐作为基准；删除新外壳造成的额外边距、高度、顶栏隐藏和导航重排。清缓存恢复原设置弹层入口。

验收：桌面侧栏和两组任务同处左侧；折叠后释放主区且可刷新保持；移动端侧栏真正收起且能展开；工具和工作流顶栏位置恢复；原版与新版控件顺序、默认展开状态和壳层几何对应。首页已选光影视觉保留。

验证：新增 Playwright 新旧版本对照检查；运行现有 live-tests 和原版 e2e；最后运行 ./scripts/check.sh。使用隔离测试后端，不调用付费模型。

回溯：checkpoint/2026-10-16-before-sidebar-layout-restore 指向本轮修改前提交。自动测试通过不代表用户验收。

- LiveShell 只提供光影主题和既有首页返回信号，导航、任务、设置、账户统一复用 AppShell；移除额外“我的项目”导航，历史记录仍在原首页。
- 原侧栏宽度 248px、任务区高度、导航顺序及设置弹层不变。收起时主区释放空间，记忆原 localStorage 状态；修复小屏 CSS 强制宽度及残留边框，隐藏内容不再接受焦点。
- 临时工作台、文艺短视频、动作迁移、数字人口播、设置：逐项对照原组件控件顺序、默认值/禁用状态、表单实际位置和尺寸、56px 固定顶栏。
- 剧本、角色/场景、分镜、参考图、视频、后期：对照原控件顺序与默认状态，恢复原固定阶段顶栏及占位。原有保存、选版、历史跳转等回归测试继续运行。
- 登录与鉴权状态保留深色视觉；首页光影背景和无标点大标题保留。移除会改动原控件几何的全局字号、标题间距、图片和复选框尺寸覆盖。
- 对照测试启动独立新旧前端并共用隔离测试后端；角色页使用包含合法版本字段的角色测试数据。文艺短视频按 DOM 与接口就绪检查，避免无关模板预览加载拖延断言。

## 后续修改边界

视觉修改不得移动导航、任务区、设置入口或操作按钮，不改变原版默认展开状态与操作顺序。验收同时检查接口行为、页面结构和实际位置，不能只以编译通过或按钮存在作为完成依据。

本轮回归还发现登录表单可能在身份就绪前提前挂载，导致延迟 hydration 保留服务端 disabled 按钮。新版恢复上一版 LiveShell 的等待身份就绪后再挂载表单的时机，并加入可控慢响应测试。鉴权接口、角色判断和表单提交逻辑未修改。
