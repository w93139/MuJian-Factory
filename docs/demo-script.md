# 幕间：五分钟面试演示脚本

**演示前**：管理员账号登录，确认 30 秒示例作品及三条短 Demo 能播放；再用邀请码在另一浏览器登录面试官视角。提前在本机保留示例 MP4 备份。现场不重新跑完整六阶段流程。

| 时间 | 操作 | 讲解重点 |
|---|---|---|
| 0:00–0:40 | 打开首页和已标记的示例作品 | 幕间把创意推进到成片，页面呈现的是约 30 秒的实际生成结果。 |
| 0:40–2:20 | 依次查看剧本、人物场景、分镜、参考图、视频片段、后期成片 | 每阶段保存结构化产物，可检查、替换和继续生成；播放最终短片。 |
| 2:20–3:20 | 打开三条快捷流水线的已有结果 | 展示文艺短片、动作迁移和数字人口播的不同入口，各播放几秒。 |
| 3:20–4:10 | 在管理员视角重新生成一张参考图，或演示沙盒中的一次图片生成 | 只做单张、最低可用分辨率的图片调用；若网络或模型排队超过约 30 秒，直接展示已保存的图片版本和生成记录。 |
| 4:10–5:00 | 切换到面试官视角，查看同一示例作品 | 邀请码账户只能浏览；生成、修改、删除和设置入口不可用。说明管理员费用和并发上限。 |

## 现场备用方案

- 网络慢或模型不可用：播放提前保存的 30 秒 MP4 与三条短 Demo，按六阶段产物继续讲解。
- 图片生成尚未完成：展示参考图历史版本和失败原因，不等待视频生成。
- 面试网络无法访问站点：本机打开备份视频与截图，随后展示仓库结构和自动化检查结果。

正式演示前，检查公开模式下沙盒和流水线历史是否适合向面试官展示。账号和 API Key 不放入幻灯片、截图或仓库。
